# Kristina Lipinskaya — «Скрипт продажів» (лендинг)

Статичний лендинг, зверстаний піксель-в-піксель за дизайн-хендоффом
(`~/Downloads/design_handoff_sales_script`). Другий продукт того ж бренду —
поруч із «Гайд для власниць fashion-брендів» (`lipinskaya-site`).

**Живий сайт:** https://sales-script-landing.netlify.app
**Репозиторій:** https://github.com/gidirimanastasia-hub/sales-script-landing (приватний)
— задеплоєний напряму з GitHub, кожен `git push` у `main` автоматично оновлює сайт.

## Що вже готово
- `index.html` / `style.css` / `script.js` — усі 9 екранів + підвал +
  двочастинний sticky-CTA + FAQ-аккордеон.
- `thank-you.html`, `payment-failed.html` — сторінки в тому ж стилі.
- Шрифти (`fonts/`) і фото (`images/`) — локальні копії з дизайн-пакета.

## Оплата, трекінг, видача PDF
Код інтеграції вже написано: кнопка WayForPay (650 ₴) на 4 місцях, Meta
Pixel + Conversions API, автовидача PDF на пошту (Resend) **і в Telegram**
(через бота — у першому лендингу такого не було). Усі дії, які може зробити
лише власниця кабінетів (WayForPay/Meta/Telegram/Netlify/Resend), — покроково
в **`README-PAYMENTS.md`**.

Юридичні посилання у футері (`Договір оферти`, `Політика конфіденційності`,
`Контакти`) поки ведуть на `#` — замінити на реальні URL перед запуском.

## Оновлення візуалу/копірайту (design_handoff_sales_script 2)
- Текст зроблено гендерно нейтральним: «менеджерка» → «менеджер», «клієнтка» → «клієнт».
- Ім'я автора виправлено на **Христина Ліпінська** (латинський вордмарк лишився `KRISTINA LIPINSKAYA`).
- Hero-абзац переписано на два коротших; додано «24 сторінки» в описах.
- На сторінці **прибрано явні обіцянки «на пошту й у Telegram»** — копірайт тепер
  каже просто «доступ відкривається після оплати». Бекенд (лист + Telegram-бот)
  технічно лишився без змін і продовжує працювати — просто це більше не
  рекламується в UI, як і просив дизайн v2.
- Фінальний екран повністю переверстано: замість цитати — чек-лист
  «Не PDF-файл, а систему продажів» із 7 пунктів.
- `thank-you.html`: якщо посилання прийшло з `?token=...` (з листа) — сторінка
  сама показує пряму кнопку «Завантажити гайд»; без токена — загальний текст
  «перевірте пошту».
